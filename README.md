# 磁力小矿工

> 给小朋友的磁力认知小游戏 —— 点一点，看看磁铁到底能吸住什么。

小松鼠矿工带你下矿洞啦！在矿洞里点选物品，判断磁铁能不能把它吸上来；三关过后还有一块磁力画板，可以把刚发现的磁力本领画下来。

## 🎮 怎么玩

- **点一下**你想吸的东西，看看磁铁能不能把它吸上来
- 吸上来的宝贝会飞进右上角的「**吸到的宝贝**」收集区
- 一关里**错 3 次**就要重新闯关 —— 慢慢想，不着急
- 建议把**平板横过来**玩，画面更大

## 🧲 三关分别在教什么

### 第 1 关 · 矿洞寻宝

认识「磁铁能吸什么」：**铁做的东西**能被吸住。

| 结果 | 物品 |
|---|---|
| ✅ 吸得住 | 回形针 · 燕尾夹 · 铁螺母 · 铁针 · 铁钉 |
| ❌ 吸不住 | 积木 · 纸杯 · 钻石 · 铜螺母 · 黄金 |

> 小提示：磁铁能吸住铁做的东西，吸不住塑料、纸、钻石和铜。

### 第 2 关 · 板子挡不挡磁力

板子下面压着回形针 —— 磁铁隔着板子，还吸得到吗？

| 结果 | 板子 | 为什么 |
|---|---|---|
| ✅ 吸得到 | 塑料板 · 木板 · 泡沫板 · 纸板 · 铜板 | 这些板子**挡不住**磁力 |
| ❌ 吸不到 | **铁板** | 铁会把磁力「引走」，磁力到不了下面的回形针 |

### 第 3 关 · 板 + 物品

板子上再放一件东西，一起判断还能不能吸上来。

| 结果 | 组合 |
|---|---|
| ✅ 吸得到 | 塑料 + 回形针 · 木板 + 铁螺母 · 纸板 + 铁钉 |
| ❌ 吸不到 | 泡沫 + 积木 · 铁板 + 燕尾夹 · 铁板 + 钻石 |

### 🎨 彩蛋页 · 磁力画板

闯关之后可以和小朋友一起涂鸦：**用手指在右边白板上画**，点「换颜色」换笔，点「重新画」清空。

> 我们发现的磁力本领，生活里到处都有 —— 磁力画板本身就用到磁力，画一张送给好朋友吧。

## 📱 怎么打开

- **在线版**：用手机 / 平板浏览器打开本仓库的 Pages 地址即可
- **离线版**：把 `index.html` **这一个文件**拷到设备上，双击就能玩 —— **不联网、不依赖任何外部文件**

## 🛠️ 技术说明

- **在线版（本仓库）**：HTML 与 22 张素材分开存放，物品图为 **WebP** 格式并**按关卡按需加载** —— 首屏体积约 **124 KB**，相比单文件版（2.5 MB）**减少约 95%**
- **离线版**：另有一份**单文件**（素材全部内嵌）可拷贝到本地，不联网也能玩
- **零依赖**：不加载任何外部库
- **适配**：手机 / 平板 / 电脑浏览器均可，已做横屏提示与误缩放防护
